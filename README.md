#N/A у тебя появился потому, что предыдущая формула скрывала любую ошибку через IFERROR(...;NA()).

Попробуй эту формулу без маскировки ошибки:

=IF(
OR(A4<$B$1;A4>$Q$1);
"Срок вне диапазона";
IF(
COUNTIF($B$1:$Q$1;A4)>0;
HLOOKUP(A4;$B$1:$Q$2;2;FALSE);
INDEX($B$2:$Q$2;1;MATCH(A4;$B$1:$Q$1;1))+
(A4-INDEX($B$1:$Q$1;1;MATCH(A4;$B$1:$Q$1;1)))*
(
INDEX($B$2:$Q$2;1;MATCH(A4;$B$1:$Q$1;1)+1)-
INDEX($B$2:$Q$2;1;MATCH(A4;$B$1:$Q$1;1))
)/
(
INDEX($B$1:$Q$1;1;MATCH(A4;$B$1:$Q$1;1)+1)-
INDEX($B$1:$Q$1;1;MATCH(A4;$B$1:$Q$1;1))
)
)
)

Проверь обязательно:

1. Срок в A4 должен быть числом, а не текстом.
2. Значения в B1:Q1 тоже должны быть числами.
3. Сроки должны идти строго по возрастанию.
4. Искомый срок должен лежать между B1 и Q1.

Для диагностики отдельно введи:

=MATCH(A4;$B$1:$Q$1;1)

Если и эта формула выдаёт #N/A, значит либо A4 меньше первого срока, либо сроки в первой строке записаны текстом.

Текстовые сроки можно быстро превратить в числа: выделить B1:Q1 → Данные → Текст по столбцам → Готово.
