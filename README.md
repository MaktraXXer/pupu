Мы оцениваем стоимость отклонения фактической досрочки от ожидаемой в неблагоприятных процентных сценариях. При снижении ставок досрочка растёт: банк раньше ожидаемого получает средства из ипотеки и вынужден реинвестировать избыточно погашенный объём по более низкой рыночной ставке — стоимость опциона отражает недополученный процентный доход. При росте ставок досрочка, наоборот, снижается: **большая часть старого ипотечного портфеля остаётся на балансе дольше ожидаемого, тогда как стоимость его замещения/фондирования уже выше**; стоимость недодосрочки оценивается через разницу между более высокой текущей ставкой новых кредитов и ставкой старого портфеля, то есть через доход, который банк мог бы получать при размещении этих средств по текущим ставкам. Таким образом, в обоих случаях мы оцениваем **стоимость неблагоприятного сочетания изменения темпа досрочного погашения и движения рыночных ставок относительно исходной ставки кредита**.
