`#N/A` здесь может появиться только из одного из двух `MATCH`:

```excel
MATCH(ROUND('Матрица стимулов'!AZ160*100;1);'Параметры S-curve'!$AP$3:$AP$503;0)
```

или

```excel
MATCH(AZ$1;'Параметры S-curve'!$AQ$2:$AZ$2;0)
```

Сам `INDEX` возвращает `#N/A`, потому что один из `MATCH` не нашел точное совпадение.

## 1. Проверь поиск строки по стимулу

В отдельной ячейке:

```excel
=ROUND('Матрица стимулов'!AZ160*100;1)
```

Посмотри полученное значение. Затем:

```excel
=MATCH(ROUND('Матрица стимулов'!AZ160*100;1);'Параметры S-curve'!$AP$3:$AP$503;0)
```

Если здесь `#N/A`, значит рассчитанного стимула нет в `AP3:AP503`.

Проверка наличия:

```excel
=COUNTIF('Параметры S-curve'!$AP$3:$AP$503;ROUND('Матрица стимулов'!AZ160*100;1))
```

Если получилось `0`, совпадение действительно не найдено.

### Наиболее вероятная причина

В `AP` значения могут выглядеть как, например, `-7,3`, но фактически храниться как:

```text
-7,2999999998
```

А искомое значение после `ROUND` равно ровно `-7,3`. `MATCH(...;0)` требует точного совпадения и может его не найти.

Проверь ближайшее значение:

```excel
=MIN(ABS('Параметры S-curve'!$AP$3:$AP$503-ROUND('Матрица стимулов'!AZ160*100;1)))
```

В старом Excel это может потребовать ввода как формулы массива.

Проще временно рядом с `AP3` сделать:

```excel
=ROUND(AP3;1)
```

и протянуть вниз. Если после этого совпадение появляется, проблема в дробной точности.

## 2. Проверь поиск столбца

Отдельно:

```excel
=MATCH(AZ$1;'Параметры S-curve'!$AQ$2:$AZ$2;0)
```

Если здесь `#N/A`, значит значение из `AZ1` отсутствует среди заголовков `AQ2:AZ2`.

Проверка:

```excel
=COUNTIF('Параметры S-curve'!$AQ$2:$AZ$2;AZ$1)
```

Возможные причины:

* число в одном месте, текст в другом;
* лишний пробел;
* разные написания категории;
* заголовок формально выглядит одинаково, но содержит скрытый символ.

Для текстового заголовка можно проверить длины:

```excel
=LEN(AZ$1)
```

и длину предполагаемого совпадающего заголовка на листе параметров.

## 3. Самая быстрая диагностика непосредственно в AZ160

Раздели формулу на части.

**Искомый стимул:**

```excel
=ROUND('Матрица стимулов'!AZ160*100;1)
```

**Номер строки:**

```excel
=MATCH(ROUND('Матрица стимулов'!AZ160*100;1);'Параметры S-curve'!$AP$3:$AP$503;0)
```

**Искомый заголовок:**

```excel
=AZ$1
```

**Номер столбца:**

```excel
=MATCH(AZ$1;'Параметры S-curve'!$AQ$2:$AZ$2;0)
```

Один из двух последних `MATCH` покажет источник ошибки.

## Если проблема в точности стимула

Надежнее округлять не только искомое значение, но и справочник. Поскольку обычный `MATCH` не умеет округлять диапазон без массивного расчета, лучший вариант — создать рядом с `AP` вспомогательный столбец:

```excel
=ROUND(AP3;1)
```

например в `BA3:BA503`, а затем искать по нему:

```excel
=IF(
    AZ$2>360-$A160;
    0;
    INDEX(
        'Параметры S-curve'!$AQ$3:$AZ$503;
        MATCH(
            ROUND('Матрица стимулов'!AZ160*100;1);
            'Параметры S-curve'!$BA$3:$BA$503;
            0
        );
        MATCH(
            AZ$1;
            'Параметры S-curve'!$AQ$2:$AZ$2;
            0
        )
    )
)
```

Это одновременно надежнее и быстрее, чем округлять весь диапазон внутри каждой матричной формулы.

Наиболее вероятно, что сломался именно первый `MATCH`: значение стимула в `AZ160` вышло за доступную сетку `AP3:AP503` либо не совпало из-за дробной точности.
