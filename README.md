Вот формулы для английской версии Excel с разделителями аргументов ; (как в русской локали):

B123 (первая строка прогноза):

excel
=IFERROR(AGGREGATE(15;6;ROW($A$1:$A$1000)/(ISNUMBER(SEARCH("прогноз";$A$1:$A$1000)));1);"")
B124 (последняя строка прогноза):

excel
=IFERROR(AGGREGATE(14;6;ROW($A$1:$A$1000)/(ISNUMBER(SEARCH("прогноз";$A$1:$A$1000)));1);"")
Никаких изменений в ссылках на листы не требуется, так как они не указаны в исходных формулах. Текст для поиска ("прогноз") остаётся на русском, поскольку соответствует содержимому ваших данных.
