Используй более простые формулы без массивов и без Ctrl+Shift+Enter.
B123 — первая строка, где в столбце A встречается «прогноз»:
=IFERROR(MATCH("*прогноз*",$A$1:$A$1000,0)+ROW($A$1)-1,"")
B124 — последняя строка, где встречается «прогноз»:
=IFERROR(LOOKUP(2,1/ISNUMBER(SEARCH("прогноз",$A$1:$A$1000)),ROW($A$1:$A$1000)),"")
