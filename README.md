58% и 42% — это доли первоначального ОСЗ, а не постоянные веса для усреднения NIM. При сокращении платежа и срока ипотечные портфели амортизируются по-разному, поэтому их доли в совокупном ОСЗ со временем меняются. Следовательно, NIM объединённого портфеля необходимо рассчитывать по суммарным денежным потокам и средневзвешенным остаткам за соответствующий период, а не как 58% NIM первого сценария + 42% NIM второго.
